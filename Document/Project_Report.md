# AI-Powered College FAQ Chatbot - Project Report

Student Name: Nisha Soni
Technology: Python, FastAPI, React, LangChain, ChromaDB, Groq API

## Overview
A college FAQ chatbot built using Retrieval-Augmented Generation (RAG).
It answers student questions about admissions, fees, hostel, exams, and placements.

## Tech Stack
- Backend: Python + FastAPI
- Frontend: React + Vite + Tailwind CSS
- RAG: LangChain + ChromaDB
- LLM: Groq API (llama-3.1-8b-instant)
- Embeddings: sentence-transformers (local, free)
